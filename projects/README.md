# Projects

Hands-on projects and experiments to apply what you're learning.

## Purpose

Learning by doing! This folder contains projects ranging from small experiments to larger applications. Each project helps solidify understanding through practical application.

## Project Types

- **Tutorials**: Following along with courses or tutorials
- **Experiments**: Testing out new technologies or concepts
- **Mini-projects**: Small, focused applications (1-3 days)
- **Challenges**: Coding challenges and solutions
- **Portfolio projects**: Larger, showcase-worthy applications

## Format

Each project should have its own folder with:

```
project-name/
├── README.md          # Project documentation
├── src/              # Source code
├── docs/             # Additional documentation
└── ...               # Other project files
```

### Project README Template

```markdown
# [Project Name]

## Description

[What does this project do?]

## Learning Goals

What I aimed to learn from this project:
- Goal 1
- Goal 2
- Goal 3

## Technologies Used

- Technology 1
- Technology 2
- Technology 3

## What I Learned

[Key takeaways from building this project]

## Challenges Faced

[Obstacles encountered and solutions]

## Future Improvements

- [ ] Improvement 1
- [ ] Improvement 2

## Setup/Usage

[How to run the project]

## Resources

[Tutorials, docs, or articles referenced]

---
Date: [Start date] - [End date]
Status: [In Progress / Completed / Paused]
```

## Tips

- Start small - simple projects teach as much as complex ones
- Document as you build, not after
- Include screenshots or demos when possible
- Note what went wrong - failures teach the most
- Revisit old projects to see how you've improved
