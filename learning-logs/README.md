# Learning Logs

Weekly or periodic reflections on learning progress, challenges, and insights.

## Format

Each learning log should capture:

```markdown
# Learning Log - [Week/Period]

Date Range: [Start] to [End]

## Summary

[High-level overview of the week's learning]

## What I Learned

- Topic 1: [Description and key takeaways]
- Topic 2: [Description and key takeaways]
- Topic 3: [Description and key takeaways]

## Projects/Practice

[What you built or practiced this week]

## Challenges

[Difficulties encountered and how you addressed them]

## Wins

[Successes, breakthroughs, or things that clicked]

## Next Week's Goals

- [ ] Goal 1
- [ ] Goal 2
- [ ] Goal 3

## Resources Used

- [Resource 1 with link]
- [Resource 2 with link]

## Reflections

[Personal thoughts on the learning process, what worked well, what to improve]
```

## Tips

- Be honest about struggles - they're part of learning
- Celebrate small wins
- Set realistic goals for the next period
- Review previous logs to see progress over time
- Use this as a tool for self-reflection and growth
