# Resources

Curated collection of learning materials, tools, and references.

## Purpose

A central place to collect and organize valuable resources you've found helpful in your learning journey.

## Organization

Resources can be organized by:
- **Topic**: Group by subject area (e.g., `web-development.md`, `data-structures.md`)
- **Type**: Group by format (e.g., `books.md`, `courses.md`, `videos.md`)
- **Status**: Track what you're currently using vs. want to explore

## Format

```markdown
# [Topic/Category Name]

## Books

### [Book Title]
- **Author**: [Author name]
- **Status**: [Reading / Completed / Want to read]
- **Rating**: ⭐⭐⭐⭐⭐
- **Notes**: [Brief thoughts or key takeaways]
- **Link**: [Where to find it]

## Courses

### [Course Name]
- **Platform**: [Udemy, Coursera, etc.]
- **Instructor**: [Name]
- **Status**: [In progress / Completed / Planned]
- **Progress**: [e.g., 40%]
- **Notes**: [What you're learning]
- **Link**: [URL]

## Articles/Tutorials

### [Article Title]
- **Author**: [Name]
- **Link**: [URL]
- **Summary**: [Quick summary]
- **Key Takeaways**: [What you learned]

## Videos/Talks

### [Video/Talk Title]
- **Creator/Speaker**: [Name]
- **Platform**: [YouTube, conference, etc.]
- **Link**: [URL]
- **Notes**: [Important points]

## Tools/Libraries

### [Tool Name]
- **Purpose**: [What it does]
- **Why useful**: [How it helps]
- **Link**: [URL]
- **Learning curve**: [Easy / Medium / Hard]

## Websites/Docs

### [Website Name]
- **Link**: [URL]
- **Purpose**: [What you use it for]
- **Highlights**: [Best features]
```

## Tips

- Add resources as you discover them
- Include brief notes on why they're valuable
- Update status as you work through materials
- Rate or rank resources to remember the best ones
- Remove resources that didn't work for you (explain why)
- Share resource lists with others learning similar topics
