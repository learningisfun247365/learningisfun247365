# Quick Start Guide

Get started with learning in public in 5 minutes!

## Step 1: Pick Your Focus (1 minute)

Edit the main [README.md](./README.md) and update the "Current Focus" section:

```markdown
## Current Focus 🎯

- Currently exploring: [What are you learning right now?]
- Working on: [Any specific project or goal?]
- Next up: [What's coming after this?]
```

## Step 2: Choose Your First Activity (1 minute)

Pick ONE to start with:

### Option A: Write a TIL (Today I Learned)
**Best for:** Daily learning, quick insights

```bash
# Copy the template
cp templates/til-template.md til/2025-11-06-my-first-til.md

# Edit the file and fill it out (2-3 minutes)
# Then commit and push!
```

### Option B: Start a Learning Log
**Best for:** Weekly reflections

```bash
# Copy the template
cp templates/learning-log-template.md learning-logs/week-01.md

# Set your goals for this week
# Update it as you go!
```

### Option C: Document a Project
**Best for:** Building something

```bash
# Create a project folder
mkdir projects/my-project

# Copy the template
cp templates/project-readme-template.md projects/my-project/README.md

# Fill it out as you build
```

## Step 3: Commit and Push (1 minute)

```bash
# Stage your changes
git add .

# Commit with a message
git commit -m "Start learning in public: [what you did]"

# Push to GitHub
git push
```

## Step 4: Build the Habit

**Daily (5-10 min):**
- Write a TIL when you learn something

**Weekly (30 min):**
- Review your week
- Update your learning log
- Plan next week

**Ongoing:**
- Document projects as you build
- Add resources as you find them
- Create notes on topics you're mastering

## Tips for Success

1. **Start small** - One TIL is enough
2. **Be consistent** - Daily beats perfect
3. **Don't overthink** - Write in your own words
4. **Embrace mistakes** - They're part of learning
5. **Make it easy** - Use the templates!
