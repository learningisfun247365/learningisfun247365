# Setting Up a Learn in Public Repository

Date: 2025-11-06

## What I learned

Today I set up my GitHub profile repository as a "learn in public" space. The key insight is that learning in public isn't about showing off expertise - it's about documenting the learning journey itself, including struggles and questions.

## Context

I wanted a structured way to track my learning progress and hold myself accountable. A public repository serves multiple purposes:
- Forces me to organize my thoughts
- Creates a searchable record I can reference later
- Potentially helps others learning similar things
- Demonstrates continuous learning to others

## Key Components

The setup includes:

1. **TIL (Today I Learned)** - Quick daily insights
2. **Learning Logs** - Weekly reflections and goal-setting
3. **Notes** - In-depth topic references
4. **Projects** - Hands-on practice documentation
5. **Resources** - Curated learning materials
6. **Templates** - Make creating content easier

## Why Templates Matter

Having templates reduces friction. Instead of thinking "how should I structure this?", I can just copy a template and fill it in. This makes it more likely I'll actually do it consistently.
