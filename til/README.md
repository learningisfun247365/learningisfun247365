# Today I Learned (TIL)

Quick, bite-sized learnings and discoveries. Each entry should be concise and focused on one thing.

## Format

Each TIL entry should follow this structure:

```markdown
# [Short descriptive title]

Date: YYYY-MM-DD

## What I learned

[Brief explanation of what you learned]

## Context

[Optional: Why this matters or where you encountered it]

## Example/Code

[Optional: Code snippet or example if applicable]

## Resources

[Optional: Links to relevant documentation or articles]
```

## Tips for Writing TILs

- Keep it short and focused (aim for 100-300 words)
- Write in your own words to reinforce learning
- Include code examples when relevant
- Link to resources for deeper learning
- Don't worry about perfection - the goal is to document learning

## Organization

TILs can be organized by:
- Date: `2025-11-06-learned-about-git-hooks.md`
- Topic: `javascript/closure-gotchas.md`
- Whatever works best for you!
