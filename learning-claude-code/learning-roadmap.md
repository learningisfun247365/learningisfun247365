# Claude Code Learning Roadmap

A comprehensive guide to learning Claude Code through hands-on mini-projects.

## Phase 1: Setup & Foundation (Start Here)

- [ ] **Understand how Claude works** - Claude uses tools (Read, Edit, Bash, etc.) to help you code
- [ ] **Set up .clauderc** - Create rules/preferences for how Claude should help you
  - *Mini project: Create a .clauderc file with your coding preferences*
- [ ] **Learn basic commands** - How to chat with Claude, /help, /clear
- [ ] **Understand Claude's context** - Claude can see your files but needs you to point to them

## Phase 2: Core Workflows (Essential Skills)

- [ ] **File operations** - Reading, editing, creating files
  - *Mini project: Ask Claude to refactor a messy file*
- [ ] **Code explanation** - Understanding existing codebases
  - *Mini project: Ask Claude to explain a confusing part of your code*
- [ ] **Bug fixing** - Debugging with Claude's help
  - *Mini project: Give Claude a broken script to fix*
- [ ] **Feature building** - Adding new functionality
  - *Mini project: "Build a simple CLI tool that [does X]"*
- [ ] **Git workflows** - Commits, PRs with Claude's help
  - *Mini project: Make changes and ask Claude to create a commit*

## Phase 3: Advanced Features (Power User)

- [ ] **Slash commands** - Custom commands in `.claude/commands/`
  - *Mini project: Create a `/test` command for your project*
- [ ] **Hooks** - Automate actions on events
  - *Mini project: Set up a pre-commit hook*
- [ ] **MCP servers** - Connect external tools (Google Drive, Slack, custom APIs)
  - *Mini project: Install an MCP server for a tool you use*
- [ ] **Multi-file projects** - Working across entire codebases
  - *Mini project: Build a multi-file REST API*

## Phase 4: Workflow Integration (Production Use)

- [ ] **CI/CD integration** - Using Claude in automated workflows
- [ ] **Team collaboration** - Sharing commands and configurations
- [ ] **Custom tooling** - Building MCP servers for your needs

## Learning Philosophy

- **Don't read everything upfront** - Learn by doing, refer to docs when needed
- **Start with what you already know** - Use Claude Code on your existing projects/languages
- **Ask Claude to explain its process** - If Claude does something unclear, ask "why did you use that approach?"
- **Experiment freely** - Claude can help you fix mistakes, so try things
- **Focus on your goals** - What do you want to build? Start there, not with abstract learning
