## Decision Framework

### When to use what?

**Use a Skill when:**
- [ ] I repeat this workflow across multiple conversations
- [ ] The task has clear, repeatable steps
- [ ] I want Claude to recognize and apply this automatically
- [ ] My team could benefit from standardized approach

**Use a Project when:**
- [ ] I need persistent context/background knowledge
- [ ] This is a specific initiative with its own workspace
- [ ] I want project-specific tone or guidelines
- [ ] I need to organize related conversations together

**Just use good prompting when:**
- [ ] It's a one-off request
- [ ] Context changes every time
- [ ] It's conversational refinement
