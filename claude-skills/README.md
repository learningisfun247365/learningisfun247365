## Current Projects

### Weekly Reflection Synthesis (Claude Skill)
Scans Obsidian weekly reflections + active workspace to surface patterns, connections, and questions for Sunday synthesis.

**Status:** Active - built and using
**Learning focus:** Claude Skills, workflow automation, pattern recognition support
**Problem solved:** Weekly synthesis was overwhelming - manual review missed patterns, formatting took forever
**Read more:** [Obsidian Reflection Workflow](resources/obsidian-reflection-workflow.md)

### Art in Context
Interactive timeline placing artists in historical/cultural context. Pulls data from MET Museum API, uses AI to generate historical context.

**Status:** In progress
**Learning focus:** APIs, data visualization, Claude prompting

### Theater RSS Feed
Aggregates schedules from ATL playhouses, theaters, and art galleries into a unified feed.

**Status:** Planned
**Learning focus:** RSS/API integration, data aggregation, scheduling
